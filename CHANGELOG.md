# Changelog

## 0.1.0-preview — 2026-11-15

First source-only public preview of the workshop dashboard.

- Home switches and sensors with persisted mappings, order, icons and thresholds.
- Two Bambu printer pages, AMS status, completion/fault notices and guarded manual controls.
- Laser power switches and a shared wall-fan control with a concise name/state row.
- Clock, weather, configurable background and opacity, scheduled dimming and red night text.
- English/German UI, QWERTY/QWERTZ keyboards and German umlaut keys.
- Fan icon available in both global switch and sensor icon pickers.
- Portable font configuration, generic examples, original neutral background and optional Home Assistant search helper.

The personalised firmware has run on one Panda Touch. This generic public preview has not been flashed to that panel because it deliberately replaces its private entity defaults and wallpaper. Stock-firmware installation and other hardware revisions need further validation.
